# DEC-027：会话列表管理与本地时间显示

> 状态：Accepted；日期：2026-10-02；负责人：Linductor。
> 工作项：M5-42；依据：DEC-008、DEC-009、DEC-004、Aki UI 设计规范。

用户要求移除会话、按新消息排序、置顶和跨日期时间显示，并明确确认移除
只影响列表，保留历史，新消息时重新出现。

## 行为与边界

Conversation 增加本地 pinned/hidden 布尔字段；不改线协议，不以 Archived
实现移除，Archived 保持终态。移除清除置顶；显式新建同端点会话可重新
显示历史。连接/断连状态更新保留这两个字段，不因上线重新显示已移除行。
仅成功插入的、端点匹配的全新入站消息重新显示隐藏会话；重复消息、送达
回报、无归属/预算拒绝不触发。入站首条消息继续遵循 CM→MM 顺序。

置顶与可见性通过 UiActions→CM 现有 ManagerPump→owner typed 字段更新。
MM 的新消息更新在单一 owner 中原子派生重新显示，不由 UI/网络线程改
Store。DB 现有 blocking worker 执行字段作业；收件写入与重新显示在同一
SQLite 事务中执行。保持既有 admission、future、失败与关闭可观测性，
不创建线程、队列或定时器。

迁移回归中 ASAN 暴露自研 Statement 移动赋值未释放旧 handle；按既有
RAII 契约修正 finalize，并以旧目标替换后 Database::close 和 ASAN 验证。

迁移 v4 追加 pinned/hidden，旧行默认 false，历史不删除。状态 upsert 不
覆盖已有本地偏好；新二进制可读旧库，旧二进制按既有版本保护拒绝 v4。

列表排序：置顶组在前，各组按最后消息的本地接受顺序降序；持久化读回
message rowid 顺序保持这一语义，远端时钟偏差不影响新消息提升。空会话
及相同排序值保持原顺序。隐藏行不派生 UI；置顶行显示文字标识。

操作入口位于选中会话的头部：置顶/取消置顶、移除会话。断开也可选中
查看历史、操作列表；发送仍按连接事实门控。只移出列表不需破坏性确认。
长名称和时间各占独立空间，时间可换行，深浅色与中英文沿现有令牌。

时间按重绘时本地时区和公历日比较，不以 24 小时推导“昨天”；周一为周
起点。今天 HH:mm、昨天“昨天 HH:mm”、本周其他日“星期X HH:mm”、
上一自然周“上周星期X HH:mm”、更早/未来日期“YYYY 年 MM 月 DD 日 HH:mm”。
英文使用对应 Yesterday / weekday / Last week weekday / YYYY-MM-DD HH:mm。
未知时间保持 --:--。历史高度缓存包含语言与本次重绘的分钟水位，
日期/语言变更后的长时间文字重新测量；不新增唤醒 timer。跨年、闰日、周一/周日和夏令时按本地日历处理。

## 验证

覆盖迁移旧数据/重开、字段持久化、连接事件不覆盖偏好、隐藏/新收件与
重复/失败、预算边界、排序与日期边界及 UiActions 接线。Debug、ASAN、
UBSAN 及最新 head 七项 CI；桌面操作验收单独记录，未执行不标通过。
